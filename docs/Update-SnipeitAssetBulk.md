# Update-SnipeitAssetBulk

## SYNOPSIS
Updates multiple hardware assets in a single bulk API request.

## SYNTAX

```
Update-SnipeitAssetBulk [-id] <Int32[]> [[-status_id] <Int32>] [[-model_id] <Int32>] [[-company_id] <Int32>]
 [[-location_id] <Int32>] [[-rtd_location_id] <Int32>] [[-supplier_id] <Int32>] [[-notes] <String>]
 [[-warranty_months] <Int32>] [[-purchase_date] <DateTime>] [[-customfields] <Hashtable>] [[-Session] <Object>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Submits an array of asset IDs to the Snipe-IT bulk edit endpoint (/api/v1/hardware/bulkedit) to update shared properties in a single batch operation.

## EXAMPLES

### EXAMPLE 1
```
Update-SnipeitAssetBulk -id @(1, 2, 3) -status_id 2 -notes "Bulk deployed during rollout"
```
