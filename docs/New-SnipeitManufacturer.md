# New-SnipeitManufacturer

## SYNOPSIS

Add a new Manufacturer to Snipe-IT asset system

## SYNTAX

```
New-SnipeitManufacturer [-name] <String> [[-image] <String>] [[-manufacturer_url] <String>]
 [[-Session] <SnipeitSession>] [[-support_email] <String>] [[-support_phone] <String>]
 [[-support_url] <String>] [[-warranty_lookup_url] <String>] [[-tag_color] <String>] [[-notes] <String>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Creates a new manufacturer on Snipe-IT system

## EXAMPLES

### EXAMPLE 1

```powershell
New-SnipeitManufacturer -name "HP"
```
