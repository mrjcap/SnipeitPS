# New-SnipeitAssetLabel

## SYNOPSIS

Generate printable asset labels from the Snipe-IT asset system.

## SYNTAX

```
New-SnipeitAssetLabel [[-asset_ids] <Int32[]>] [[-asset_tags] <String[]>] [[-Session] <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Generates printable PDF asset labels via `POST /api/v1/hardware/labels`. Accepts an array of asset tags or asset IDs.
When asset IDs are supplied, they are resolved to asset tags prior to label generation. If any asset ID fails to
resolve, execution halts immediately with an error to prevent generating incomplete label sets. All resolution and
generation requests are guarded by ShouldProcess to guarantee zero HTTP requests under `-WhatIf`.

## EXAMPLES

### EXAMPLE 1

```powershell
New-SnipeitAssetLabel -asset_ids 1,2,3
```

### EXAMPLE 2

```powershell
New-SnipeitAssetLabel -asset_tags 'AST-001', 'AST-002'
```
