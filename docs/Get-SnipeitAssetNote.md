# Get-SnipeitAssetNote

## SYNOPSIS

Gets manual notes for an asset.

## SYNTAX

```
Get-SnipeitAssetNote [-asset_id] <Int32> [-preserveResponse] [-Session <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Retrieves the unpaginated manual notes recorded on an asset via GET /api/v1/notes/{asset}/index. Returns each note
record from payload.notes decorated with SnipeitPS.AssetNote.

## EXAMPLES

### EXAMPLE 1

```
Get-SnipeitAssetNote -asset_id 101
```

### EXAMPLE 2

```
Get-SnipeitAsset -id 101 | Get-SnipeitAssetNote
```
