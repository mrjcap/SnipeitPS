# Get-SnipeitLocationAssignment

## SYNOPSIS

Gets assets or accessories assigned to a specific location from Snipe-IT.

## SYNTAX

```
Get-SnipeitLocationAssignment [-AssignedType] <String> [-id] <Int32> [-offset <Int32>] [-limit <Int32>] [-all]
 [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Retrieves assets or accessories checked out or assigned to a target location in Snipe-IT. Assigned assets are returned
in a single unpaginated response; assigned accessories support pagination.

## EXAMPLES

### EXAMPLE 1

```
Get-SnipeitLocationAssignment -AssignedType Asset -id 3
```

### EXAMPLE 2

```
Get-SnipeitLocationAssignment -AssignedType Accessory -id 3 -All
```
