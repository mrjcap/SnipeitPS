# Remove-SnipeitAssetBulk

## SYNOPSIS
Deletes multiple hardware assets in a single bulk API request.

## SYNTAX

```
Remove-SnipeitAssetBulk [-id] <Int32[]> [[-Session] <Object>] [-ProgressAction <ActionPreference>] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Submits an array of asset IDs to the Snipe-IT bulk delete endpoint (/api/v1/hardware/bulkdelete) to delete assets in batch.

## EXAMPLES

### EXAMPLE 1
```
Remove-SnipeitAssetBulk -id @(101, 102, 103)
```
