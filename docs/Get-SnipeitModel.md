# Get-SnipeitModel

## SYNOPSIS

Gets a list of Snipe-IT Models

## SYNTAX

### Search (Default)

```
Get-SnipeitModel [-search <String>] [-sort <String>] [-order <String>] [-limit <Int32>] [-offset <Int32>]
 [-all] [-name <String>] [-model_number <String>] [-notes <String>] [-category_id <Int32>]
 [-depreciation_id <Int32>] [-requestable <Boolean>] [-status <String>] [-filter <String>]
 [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### Get with ID

```
Get-SnipeitModel [-id <Int32>] [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Gets a list of Snipe-IT asset models or a specific model by ID.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-SnipeitModel -search "DL380"
```

### EXAMPLE 2

```powershell
Get-SnipeitModel -id 1
```
