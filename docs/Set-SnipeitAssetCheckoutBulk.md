# Set-SnipeitAssetCheckoutBulk

## SYNOPSIS

Checks out multiple hardware assets to a user, location, or asset.

## SYNTAX

```
Set-SnipeitAssetCheckoutBulk [-id] <Int32[]> [-assigned_id] <Int32> [[-checkout_to_type] <String>]
 [[-note] <String>] [[-expected_checkin] <DateTime>] [[-checkout_at] <DateTime>] [[-status_id] <Int32>]
 [[-Session] <SnipeitSession>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Sequentially or in batch checks out multiple asset IDs to a designated target (user, location, or asset).

## EXAMPLES

### EXAMPLE 1

```
Set-SnipeitAssetCheckoutBulk -id @(1, 2, 3) -assigned_id 42 -checkout_to_type user
```
