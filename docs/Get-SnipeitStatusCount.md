# Get-SnipeitStatusCount

## SYNOPSIS

Gets asset count summaries by status label or meta status type.

## SYNTAX

```
Get-SnipeitStatusCount [[-By] <String>] [-preserveResponse] [-Session <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Retrieves asset count summaries formatted for status reporting via GET /api/v1/statuslabels/assets/name (by label name)
or GET /api/v1/statuslabels/assets/type (by meta status type). Emits structured SnipeitPS.StatusCount objects retaining
label, count, and chart color.

## EXAMPLES

### EXAMPLE 1

```
Get-SnipeitStatusCount -By Name
```

### EXAMPLE 2

```
Get-SnipeitStatusCount -By Type
```
