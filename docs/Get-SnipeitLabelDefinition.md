# Get-SnipeitLabelDefinition

## SYNOPSIS

Gets label definitions from Snipe-IT.

## SYNTAX

### All (Default)

```
Get-SnipeitLabelDefinition [-search <String>] [-limit <Int32>] [-offset <Int32>] [-preserveResponse]
 [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### ByName

```
Get-SnipeitLabelDefinition [-name] <String> [-preserveResponse] [-Session <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Queries label definition metadata via GET /api/v1/labels or retrieves a single label definition by name via GET
/api/v1/labels/{name}.

## EXAMPLES

### EXAMPLE 1

```
Get-SnipeitLabelDefinition
```

### EXAMPLE 2

```
Get-SnipeitLabelDefinition -name 'Default\Avery5160'
```
