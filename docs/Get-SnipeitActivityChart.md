# Get-SnipeitActivityChart

## SYNOPSIS

Gets the activity report chart data from Snipe-IT.

## SYNTAX

### ByDays (Default)

```
Get-SnipeitActivityChart [[-days] <Int32>] [-preserveResponse] [-Session <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### ByDateRange

```
Get-SnipeitActivityChart -start_date <DateTime> -end_date <DateTime> [-preserveResponse]
 [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Retrieves activity metrics (user, asset, component, consumable, license, accessory events, and maintenance actions) via
GET /api/v1/reports/activity/chart. Supports either a preset number of days (7, 14, 30, 60, 90, 180, 365) or a custom
date range. Preserves all labels, comparison intervals, and series as a single structured SnipeitPS.ActivityChart
object.

## EXAMPLES

### EXAMPLE 1

```
Get-SnipeitActivityChart
```

### EXAMPLE 2

```
Get-SnipeitActivityChart -days 90
```

### EXAMPLE 3

```
Get-SnipeitActivityChart -start_date ([datetime]'2026-01-01') -end_date ([datetime]'2026-03-31')
```
