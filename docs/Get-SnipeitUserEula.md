# Get-SnipeitUserEula

## SYNOPSIS

Gets the EULAs for a specific user

## SYNTAX

```
Get-SnipeitUserEula [-id] <Int32> [[-Session] <SnipeitSession>] [[-limit] <Int32>] [[-offset] <Int32>] [-all]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Gets the EULA acceptance status for a specific Snipe-IT user.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-SnipeitUserEula -id 1
```
