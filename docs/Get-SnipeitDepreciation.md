# Get-SnipeitDepreciation

## SYNOPSIS

Gets depreciation schedules from Snipe-IT.

## SYNTAX

### ByFilter (Default)

```
Get-SnipeitDepreciation [-search <String>] [-filter <String>] [-sort <String>] [-order <String>]
 [-offset <Int32>] [-limit <Int32>] [-all] [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

### ById

```
Get-SnipeitDepreciation -id <Int32> [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Retrieves one or more depreciation schedules from Snipe-IT. Supports retrieving a specific schedule by ID, or searching
and listing schedules with sorting, filtering, and pagination.

## EXAMPLES

### EXAMPLE 1

```
Get-SnipeitDepreciation -All
```

### EXAMPLE 2

```
Get-SnipeitDepreciation -id 5
```

### EXAMPLE 3

```
Get-SnipeitDepreciation -search "Computer" -sort "name" -order "asc"
```
