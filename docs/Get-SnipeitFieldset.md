# Get-SnipeitFieldset

## SYNOPSIS

Returns a fieldset or list of Snipe-IT Fieldsets

## SYNTAX

```
Get-SnipeitFieldset [[-id] <Int32>] [[-Session] <SnipeitSession>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Gets Snipe-IT fieldsets or a specific fieldset by ID.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-SnipeitFieldset
Get all fieldsets
```

### EXAMPLE 2

```powershell
Get-SnipeitFieldset | Where-Object {$_.name -eq "Windows" }
Gets fieldset by name
```
