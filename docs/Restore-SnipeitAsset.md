# Restore-SnipeitAsset

## SYNOPSIS

Restores a deleted asset in Snipe-IT

## SYNTAX

```
Restore-SnipeitAsset [-id] <Int32[]> [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION

Restores a deleted asset in Snipe-IT

## EXAMPLES

### EXAMPLE 1

```powershell
Restore-SnipeitAsset -id 1
```
