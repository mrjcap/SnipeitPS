# New-SnipeitComponent

## SYNOPSIS

Create a new component

## SYNTAX

```
New-SnipeitComponent [-name] <String> [-category_id] <Int32> [-qty] <Int32> [[-company_id] <Int32>]
 [[-location_id] <Int32>] [[-order_number] <String>] [[-purchase_date] <DateTime>] [[-purchase_cost] <String>]
 [[-image] <String>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Creates a new component on Snipe-IT system

## EXAMPLES

### EXAMPLE 1

```powershell
New-SnipeitComponent -name 'Display adapter' -category_id 3 -qty 10
```
