# Set-SnipeitInfo

## SYNOPSIS

Sets authentication information. Deprecated, use Connect-SnipeitPS instead.

## SYNTAX

```
Set-SnipeitInfo [-url] <Uri> [-apiKey] <String> [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Deprecated compatibility function that Sets API Key and URL used to connect to Snipe-IT system. Please use
Connect-SnipeitPS instead.

## EXAMPLES

### EXAMPLE 1

```powershell
Set-SnipeitInfo -url $url -apiKey $myapikey -Verbose
```
