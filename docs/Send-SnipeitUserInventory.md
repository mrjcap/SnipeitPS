# Send-SnipeitUserInventory

## SYNOPSIS

Emails the current inventory of assigned assets to a user.

## SYNTAX

```
Send-SnipeitUserInventory [-id] <Int32[]> [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Sends an email notification to a user with their currently assigned hardware, licenses, accessories, and consumables via
POST /api/v1/users/{id}/email. Requires user-update permissions. Supports pipeline input for user ID.

## EXAMPLES

### EXAMPLE 1

```
Send-SnipeitUserInventory -id 42
```

### EXAMPLE 2

```
10, 20, 30 | Send-SnipeitUserInventory
```
