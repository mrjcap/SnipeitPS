# Sync-SnipeitAsset

## SYNOPSIS

Declaratively synchronizes a hardware asset with Snipe-IT, ensuring desired state with zero redundant writes.

## SYNTAX

```
Sync-SnipeitAsset [-asset_tag] <String> [[-serial] <String>] [[-name] <String>] [[-model_id] <Int32>]
 [[-status_id] <Int32>] [[-company_id] <Int32>] [[-location_id] <Int32>] [[-notes] <String>]
 [[-customfields] <Hashtable>] [[-Ensure] <String>] [[-Session] <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Performs idempotent reconciliation between desired state properties and the remote Snipe-IT asset. If Ensure = 'Present'
and the asset does not exist (queried by asset_tag or serial), creates the asset. If the asset exists, compares
properties (name, model_id, status_id, company_id, location_id, serial, notes) and updates ONLY if drift is detected. If
Ensure = 'Absent' and the asset exists, deletes the asset.

## EXAMPLES

### EXAMPLE 1

```
Sync-SnipeitAsset -asset_tag "SRV-001" -name "Core Router" -model_id 12 -status_id 1 -Ensure Present
```

## NOTES

When running with -WhatIf, Sync-SnipeitAsset performs a read-only GET query to retrieve current remote asset state for
drift evaluation, while strictly guaranteeing that zero mutative HTTP requests (POST, PATCH, DELETE) or writes are
executed.
