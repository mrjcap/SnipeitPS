# Get-SnipeitStatus

## SYNOPSIS

Gets a list of Snipe-IT Status Labels

## SYNTAX

### Search (Default)
```
Get-SnipeitStatus [-search <String>] [-name <String>] [-sort <String>] [-order <String>] [-limit <Int32>]
 [-offset <Int32>] [-all] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### Get with ID
```
Get-SnipeitStatus [-id <Int32>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Gets a list of Snipe-IT status labels or a specific status label by ID.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-SnipeitStatus -search "Ready to Deploy"
```

### EXAMPLE 2

```powershell
Get-SnipeitStatus -id 3
```
