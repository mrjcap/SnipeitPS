# Clear-SnipeitCache

## SYNOPSIS
Clears the in-memory argument completer and response cache for SnipeitPS.

## SYNTAX

```
Clear-SnipeitCache [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION
Flushes cached lookups (such as Models, Categories, Statuses, Locations, Companies, Suppliers, and Departments) used by dynamic argument completers and internal queries.

## EXAMPLES

### EXAMPLE 1
```
Clear-SnipeitCache
```
