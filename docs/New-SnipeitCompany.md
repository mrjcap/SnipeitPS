# New-SnipeitCompany

## SYNOPSIS

Creates a new Company

## SYNTAX

```
New-SnipeitCompany [-name] <String> [[-image] <String>] [[-parent_id] <Int32>] [[-Session] <SnipeitSession>]
 [[-phone] <String>] [[-fax] <String>] [[-email] <String>] [[-tag_color] <String>] [[-notes] <String>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Creates a new company on Snipe-IT system

## EXAMPLES

### EXAMPLE 1

```powershell
New-SnipeitCompany -name "Acme Company"
```
