# Set-SnipeitCompany

## SYNOPSIS

Updates company name

## SYNTAX

```
Set-SnipeitCompany [-id] <Int32[]> [[-name] <String>] [[-image] <String>] [[-parent_id] <Int32>]
 [-image_delete] [[-RequestType] <String>] [[-Session] <SnipeitSession>] [[-phone] <String>] [[-fax] <String>]
 [[-email] <String>] [[-tag_color] <String>] [[-notes] <String>] [-ProgressAction <ActionPreference>] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Updates company name on Snipe-IT system

## EXAMPLES

### EXAMPLE 1

```powershell
Set-SnipeitCompany -id 1 -name "Acme Corp"
```
