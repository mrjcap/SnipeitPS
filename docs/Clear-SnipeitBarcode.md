# Clear-SnipeitBarcode

## SYNOPSIS

Purges server-cached barcode image files.

## SYNTAX

```
Clear-SnipeitBarcode [[-Session] <SnipeitSession>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION

Calls POST /api/v1/settings/purge_barcodes to delete cached PNG barcode files on the Snipe-IT server. Requires superuser
privileges. Uses high confirmation impact.

## EXAMPLES

### EXAMPLE 1

```
Clear-SnipeitBarcode
```
