# Get-SnipeitBackup

## SYNOPSIS

Gets a list of available Snipe-IT backups

## SYNTAX

```
Get-SnipeitBackup [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Gets list of available backups from the Snipe-IT asset management system.

## EXAMPLES

### EXAMPLE 1

Get-SnipeitBackup
