# Set-SnipeitManufacturer

## SYNOPSIS

Updates an existing Manufacturer in Snipe-IT asset system

## SYNTAX

```
Set-SnipeitManufacturer [-id] <Int32[]> [[-name] <String>] [[-image] <String>] [[-manufacturer_url] <String>]
 [-image_delete] [[-RequestType] <String>] [[-Session] <SnipeitSession>] [[-support_email] <String>]
 [[-support_phone] <String>] [[-support_url] <String>] [[-warranty_lookup_url] <String>]
 [[-tag_color] <String>] [[-notes] <String>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION

Updates manufacturer on Snipe-IT system

## EXAMPLES

### EXAMPLE 1

```powershell
Set-SnipeitManufacturer -id 1 -name "HP Inc."
```
