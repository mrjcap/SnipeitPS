# Get-SnipeitAccessoryOwner

## SYNOPSIS

Gets a list of checked out accessories

## SYNTAX

```
Get-SnipeitAccessoryOwner [-id] <Int32> [[-Session] <SnipeitSession>] [[-search] <String>] [[-limit] <Int32>]
 [[-offset] <Int32>] [-all] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Gets a list of checked out accessories

## EXAMPLES

### EXAMPLE 1

```powershell
Get-SnipeitAccessoryOwner -id 1
```
