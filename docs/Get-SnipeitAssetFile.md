# Get-SnipeitAssetFile

## SYNOPSIS

Gets files associated with an asset

## SYNTAX

### Search (Default)
```
Get-SnipeitAssetFile -id <Int32> [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### Get with file ID
```
Get-SnipeitAssetFile -id <Int32> [-file_id <Int32>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Gets files associated with a specific Snipe-IT asset.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-SnipeitAssetFile -id 1
```
