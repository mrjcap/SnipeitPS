# Get-SnipeitAccountEula

## SYNOPSIS

Gets End User License Agreements accepted by the user.

## SYNTAX

```
Get-SnipeitAccountEula [[-user_id] <Int32>] [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Retrieves accepted EULAs for the authenticated user or for a direct report if the manager view is enabled. Queries GET
/api/v1/account/eulas.

## EXAMPLES

### EXAMPLE 1

```
Get-SnipeitAccountEula
```

### EXAMPLE 2

```
Get-SnipeitAccountEula -user_id 5
```
