# New-SnipeitDepartment

## SYNOPSIS

Creates a department

## SYNTAX

```
New-SnipeitDepartment [-name] <String> [[-company_id] <Int32>] [[-location_id] <Int32>] [[-manager_id] <Int32>]
 [[-notes] <String>] [[-image] <String>] [[-Session] <SnipeitSession>] [[-phone] <String>] [[-fax] <String>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Creates a new department on Snipe-IT system

## EXAMPLES

### EXAMPLE 1

```powershell
New-SnipeitDepartment -name "Department1" -company_id 1 -location_id 1 -manager_id 3
```
