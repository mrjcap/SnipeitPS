# New-SnipeitPersonalAccessToken

## SYNOPSIS

Creates a new personal access token for the authenticated user.

## SYNTAX

```
New-SnipeitPersonalAccessToken [[-name] <String>] [-Session <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Mints a new personal access token via POST /api/v1/account/personal-access-tokens. The generated secret is returned
exactly once and converted immediately into a SecureString property (TokenSecret) on the emitted
SnipeitPS.PersonalAccessToken object. Default formatting suppresses the secret.

## EXAMPLES

### EXAMPLE 1

```
$newToken = New-SnipeitPersonalAccessToken -name "CI Deployment Token"
```
