# Get-SnipeitOrderItem

## SYNOPSIS

Lists acquisition lines from the current Snipe-IT API.

## SYNTAX

### Unscoped (Default)

```
Get-SnipeitOrderItem [-search <String>] [-sort <String>] [-order <String>] [-limit <Int32>] [-offset <Int32>]
 [-all] [-preserveResponse] [-Session <SnipeitSession>] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

### Item

```
Get-SnipeitOrderItem -EntityType <String> -item_id <Int32> [-search <String>] [-sort <String>]
 [-order <String>] [-limit <Int32>] [-offset <Int32>] [-all] [-preserveResponse] [-Session <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### Model

```
Get-SnipeitOrderItem -asset_model_id <Int32> [-search <String>] [-sort <String>] [-order <String>]
 [-limit <Int32>] [-offset <Int32>] [-all] [-preserveResponse] [-Session <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Reads GET /api/v1/order-items. Scope by inventory type and item_id, or aggregate assets by asset_model_id. Unscoped
listing requires server superuser permission. Costs and dates retain the server's transformed representation. This API
does not expose order creation, editing or deletion.

## EXAMPLES

### EXAMPLE 1

```
Get-SnipeitOrderItem -EntityType Accessory -item_id 7 -all
```

### EXAMPLE 2

```
Get-SnipeitOrderItem -asset_model_id 4 -sort purchase_date -order desc
```
