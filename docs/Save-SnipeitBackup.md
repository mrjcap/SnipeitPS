# Save-SnipeitBackup

## SYNOPSIS

Downloads a Snipe-IT backup file

## SYNTAX

```
Save-SnipeitBackup [-filename] <String> [-path] <String> [-ProgressAction <ActionPreference>] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Downloads a Snipe-IT backup file to a local directory.

## EXAMPLES

### EXAMPLE 1

```powershell
Save-SnipeitBackup -filename "2024-01-15-backup.sql" -path "C:\Backups"
```
