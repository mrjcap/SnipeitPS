# Get-SnipeitAuditOverdue

## SYNOPSIS

Gets assets overdue for audit

## SYNTAX

```
Get-SnipeitAuditOverdue [[-limit] <Int32>] [[-offset] <Int32>] [-all] [[-Session] <SnipeitSession>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Gets assets that are overdue for audit from the Snipe-IT asset management system.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-SnipeitAuditOverdue
```
